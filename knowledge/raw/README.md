# raw/ — корзина сырья для базы знаний

Сюда агенты (и ты) складывают **необработанное сырьё**: присланные документы,
черновики, заметки, выгрузки, куски текста «на потом».

Дальше любой агент по запросу систематизирует сырьё:
сырьё → аккуратный `knowledge/<topic>.md` → запись в `knowledge/INDEX.md`.

После обработки файл из raw/ можно удалить или пометить `[обработано]`.

Это входящая корзина, а не постоянное хранилище — не ищи знания здесь, ищи в `INDEX.md`.
