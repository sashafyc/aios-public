# Голосовые и транскрибация (AssemblyAI)

## Что даёт

- **Голосовые в любом топике** — мост сам транскрибирует voice → текст → агент отвечает.
- **Агент Скрайбер** — транскрибация аудио/видео файлов и YouTube-ссылок.

Оба используют один ключ `ASSEMBLYAI_API_KEY`.

## Подключение

1. Зайди на **assemblyai.com**, зарегистрируйся (бесплатно $50 на старте).
2. Settings → API Keys → скопируй ключ.
3. Пропиши в `bridge/.env`:
   ```
   ASSEMBLYAI_API_KEY=твой_ключ
   ```
4. Рестарт моста.
5. Проверка: `python3 bridge/doctor.py` → строка ASSEMBLYAI_API_KEY должна быть ✅.

Через Сисадмина: просто скажи «подключи голосовые» — проведёт по шагам.

## YouTube (для Скрайбера)

Нужны `yt-dlp` и `ffmpeg`:
```bash
pip install yt-dlp
# ffmpeg: brew install ffmpeg (Mac) / apt install ffmpeg (Ubuntu)
```
Скрайбер качает аудио через yt-dlp → транскрибирует через AssemblyAI.

## Без ключа

Если `ASSEMBLYAI_API_KEY` не задан — голосовые не транскрибируются, Скрайбер не работает. Остальная система работает нормально (doctor покажет warning, не error).
