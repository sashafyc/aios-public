# Upgrade notes — рекомендуемые изменения настроек агентов

Этот файл — мост между релизом и «мягкими» агентами. Инструкции рабочих агентов
(Ассистент, Скрайбер, кастомные) — **user-owned**: обновление их НЕ перезаписывает
(см. [agents.md](add-agent.md) и модель hard/soft в `agents/sysadmin/router.md`).
Поэтому если новая версия улучшает поведение агентов, эти улучшения едут СЮДА как
**рекомендации**, а применяет их Сисадмин — с согласия пользователя.

## Как это работает

1. **Мейнтейнер** при выкатке версии с улучшениями инструкций агентов добавляет
   секцию `## vX.Y.Z` ниже: что и каким агентам рекомендуется дописать/изменить.
2. **update.sh** после установки видит секцию для новой версии и в Telegram-сообщении
   подсказывает: «есть рекомендуемые изменения агентов».
3. **Сисадмин**, когда пользователь говорит «применить рекомендации»: читает этот файл,
   показывает саммари рекомендаций для установленной версии, спрашивает «обновить агентов?».
   - **Да** → дописывает рекомендованное в инструкции соответствующих агентов
     (`agents/<agent>/CLAUDE.md`).
   - **Нет** → ничего не меняет.

## Формат секции (для мейнтейнера)

```
## v1.0.1
- **assistant**: добавить правило «…» в раздел «…».
- **scriber**: уточнить поведение при «…».
- (агенты, которых не касается — не перечислять)
```

Если в релизе нет изменений инструкций агентов — секцию не добавляют, и Сисадмин
ничего не предлагает.
