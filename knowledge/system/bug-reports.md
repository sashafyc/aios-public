# Баг-репорты

Сбор багов — **local-first**, отправка **опциональна** (opt-in, по умолчанию выкл).
Полная политика приватности — `PRIVACY.md` (в корне).

## Как работает

- **Локально всегда:** баги пишутся в `logs/bugs/bugs.jsonl` (редактированные: секреты
  замаскированы, пути → `~`).
- **Отправка — только при opt-in:** если в `.env` `AIOS_BUGREPORT=1` и задан
  `AIOS_BUGREPORT_URL`, отчёт уходит на endpoint разработчика. Иначе — никуда.
- **Аноним:** случайный `install_id` (для дедупа), без личных данных.

## Триггеры

- **Вручную (пользователь):** «нашёл баг / не работает / почини» → запиши:
  ```bash
  $AIOS_ROOT/.venv/bin/python $AIOS_ROOT/bridge/bug_report.py \
    --source user --desc "<тех. описание>" [--agent <имя>] [--error "<текст ошибки>"]
  ```
  Описывай **технически и по делу** (что делал, что упало, текст ошибки). Скажи юзеру
  что записал, и чини сам если можешь.
- **Авто:** мост сам ловит нетривиальные (UNKNOWN) ошибки раннера и пишет их.
  Транзиентные (rate-limit/auth/overload) багами не считаются.

## Включить / выключить отправку

Переключи `AIOS_BUGREPORT` (0/1) в `$AIOS_ROOT/bridge/.env` → рестарт моста.
Объясни пользователю: отправка анонимна и редактирована, всё дублируется локально,
выключить можно в любой момент (PRIVACY.md).

## Посмотреть собранные баги

```bash
cat $AIOS_ROOT/logs/bugs/bugs.jsonl
```
