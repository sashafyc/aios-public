# База знаний системы

Документация для Сисадмина (и любопытных). Сюда же можно класть свои .md — агенты смогут читать.

## system/ — как устроена система

| Документ | О чём |
|---|---|
| `system/architecture.md` | Обзор: мост, агенты, routing, где что лежит |
| `system/add-agent.md` | Как создать агента (механика) |
| `system/runners.md` | Бэкенды LLM: claude/codex/deepseek/gemini, авторизация, стоимость, переключение |
| `system/delegation.md` | Делегация: теги, иерархия, настройка |
| `system/voice.md` | Голосовые и транскрибация (AssemblyAI) |
| `system/cron.md` | Запланированные задачи (trigger.py) |
| `system/state-machine.md` | Состояния агента, daily reset, keep-alive, compact |
| `system/troubleshooting.md` | Что делать когда что-то сломалось |

## Куда класть свои знания

Любые `.md` в `knowledge/` — справочники, инструкции, базы фактов. Агент (через Сисадмина) может читать их при необходимости.
