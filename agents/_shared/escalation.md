# Эскалация к Сисадмину — что делать при ошибке системы

Если ты не можешь выполнить задачу из-за **системной проблемы** (а не из-за самой задачи):
- не хватает программы/библиотеки («command not found», «No module named ...»)
- нет прав на файл/действие
- кончилось место, сломан доступ, не настроен ключ API

→ **Не пытайся чинить систему сам и не сдавайся молча.** Скажи пользователю чётко:

> ⚠️ Не могу — [конкретная причина, например: «не установлена библиотека для чтения .docx»].
> Это к Сисадмину. **Перешли ему это сообщение** в топик ⚙️ Система — он починит, потом напиши мне «исправили», и я продолжу.

Правила сообщения об ошибке:
1. **Назови точную причину** — что именно не хватает (имя пакета/библиотеки/файла, текст ошибки). Сисадмину это нужно для диагностики.
2. **Одно сообщение** — пользователь перешлёт его целиком Сисадмину.
3. После «исправили» — **продолжи с того места**, где остановился.

Это НЕ относится к ошибкам самой задачи (неверные данные, непонятный запрос) — там просто уточни у пользователя.
