# context.md — спецификация

Постоянная память агента. Переживает рестарт, compact, daily reset. Читай при старте сессии.

## Структура

```
## 🔥 Активное — что в работе (макс 5-7 записей)
- YYYY-MM-DD: task-NNN — [задача]. Статус: [что/следующий шаг].

## ⏳ Ожидает — открытые WAITING
- task-NNN: ждём [RESULT:agent:id] — [что ожидаем]

## ✅ Недавнее — закрытые за 7 дней
- YYYY-MM-DD: task-NNN [DONE] — [итог, путь к артефакту]

## 📌 Постоянное — роль, модель, топик, факты о пользователе, ссылки

## 🧠 Выученное — установки пользователя, влияющие на будущие решения
```

## Как обновлять

Вариант 1: Write tool → файл, потом тег `[MEMORY_UPDATE]` в ответе.
Вариант 2: `[MEMORY_UPDATE]` ... `[/MEMORY_UPDATE]` — bridge запишет сам.

Обновляй при: новая задача, задача завершена, получен RESULT, новая установка от пользователя.

## Daily reset

Bridge ежедневно (время в .env: DAILY_RESET_HOUR/MINUTE) копирует context.md → `context_archive/YYYY-MM-DD.md`, сбрасывает сессию → IDLE. context.md НЕ обнуляется. WAITING-агенты не сбрасываются.

Секции «📌 Постоянное» и «🧠 Выученное» — живут вечно. «🔥 Активное» чистится по мере закрытия задач.
