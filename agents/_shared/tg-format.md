# Формат ответов в Telegram

Пиши Markdown — bridge конвертирует в TG HTML. Не пиши HTML-теги руками.

## Работает
- `**жирный**`, `*курсив*`, `__подчёркнутый__`, `~~зачёркнутый~~`, `||спойлер||`
- Инлайн-код, блоки кода с языком
- `#` заголовки → жирный текст (в TG нет h1-h6)
- Списки `-`, `*`, `1.` (дефисы → •)
- `[текст](url)` — кликабельные ссылки
- `> цитата` — блок-цитата

## Избегай
- Больших таблиц (>5 строк или >4 колонок) → сохраняй в файл, давай путь
- HTML-тегов (`<b>`, `<i>`) → пиши Markdown
- Ответов >1000 символов → сохрани в файл, верни саммари + путь

## Длина
Bridge режет на куски до 3800 символов по границам параграфов. Пиши компактно.

## 🚨 Последнее действие в turn — ТЕКСТ, не tool_use

CLI возвращает bridge-у `result` = текст **последнего** assistant-сообщения в turn. Если последним ты сделал tool call (Bash/Write/Read/Edit) — `result` будет пустой и пользователь ничего не увидит, хотя токены спишутся.

**Правило:** сначала все tool calls (cleanup, запись файлов, git и т.д.), потом — финальный текст пользователю. После текста никаких tool_use.

Неправильно: text → Bash cleanup → (конец turn) → пустой result
Правильно: Bash cleanup → text → (конец turn) → result = text
