# База знаний — общая память команды

`knowledge/` (в корне системы, `$AIOS_ROOT/knowledge/`) — общая память ВСЕЙ команды агентов. В отличие от твоего `context.md` (личная оперативная память) — сюда складываются долгие знания, доступные всем агентам.

## 🔎 Сначала ищи здесь

**Перед тем как ресёрчить с нуля, выполнять задачу или отвечать на вопрос про систему / пользователя / его проекты — сначала проверь базу знаний.** Возможно, ответ уже есть.

- `$AIOS_ROOT/knowledge/INDEX.md` — оглавление: что и где лежит. Начинай отсюда.
- `$AIOS_ROOT/knowledge/system/` — как устроена сама система.
- `$AIOS_ROOT/knowledge/<topic>.md` — пользовательские знания (справочники, факты, правила, данные о проектах).

## ➕ Как вносить знания

1. **Сырьё** (черновики, присланные документы, заметки, выгрузки) → клади в `$AIOS_ROOT/knowledge/raw/`.
2. **Систематизируй** — оформи в аккуратный `$AIOS_ROOT/knowledge/<topic>.md` (структурированно, по делу).
3. **ОБЯЗАТЕЛЬНО зарегистрируй** новый файл в `$AIOS_ROOT/knowledge/INDEX.md` (строка: тема → путь). Без этого другие агенты его не найдут.
4. Обработанное сырьё из `raw/` можно удалить или пометить `[обработано]`.

> Если пользователь говорит «запомни это / занеси в базу / сохрани справочник» — это сигнал внести в `knowledge/`, а не только в свой `context.md`.

## 🗂 Где что хранить (правило размещения)

| Что | Куда |
|---|---|
| Твоя оперативная память (текущие задачи, предпочтения юзера) | свой `context.md` |
| Долгие общие знания (справочники, факты, базы, правила) | `knowledge/<topic>.md` + запись в INDEX |
| Сырьё на обработку | `knowledge/raw/` |
| Твои рабочие черновики и артефакты | `workspace/temp/<ты>/` (чистится периодически) |
| Общие файлы навсегда (шаблоны, базы данных, важные ассеты) | `workspace/permanent/` (общая, не чистится) |
