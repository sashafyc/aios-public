# Иерархия делегирования

Из коробки три агента:

```
   Пользователь
        │
 ┌──────┼────────┐
 Ассистент  Сисадмин  Скрайбер
     │
  (делегирует) → Скрайбер
```

## Правила

- **Ассистент** — рабочий агент. Может делегировать Скрайберу (транскрибация).
- **Сисадмин** — управляет системой, не делегирует (сам делает через tools).
- **Скрайбер** — выполняет транскрибацию, возвращает RESULT инициатору.
- Делегация в агента не из списка `can_delegate_to` — bridge молча отбросит.

## Как добавить агента

Через Сисадмина: напиши ему «создай агента X». Он создаст папку, CLAUDE.md, симлинки, добавит в agents.toml и при необходимости настроит делегацию (`can_delegate_to`).

Подробности механики — `knowledge/system/delegation.md`.
