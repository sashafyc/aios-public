# Теги

Все команды bridge — теги в квадратных скобках. Две формы:

**Однострочная:** `[DELEGATE:scriber] Транскрибируй это видео`
**Многострочная:** `[DELEGATE:scriber:task-42]` ... `[/DELEGATE]`

| Тег | Что делает |
|---|---|
| `[DELEGATE:<agent>[:task-id]]` | Передать задачу другому агенту |
| `[RESULT:<agent>:<task-id>]` | Отчёт обратно инициатору |
| `[WAITING_FOR:<agent>[:task-id]]` | Уйти в WAITING (idle timer выкл) |
| `[ASK_USER]` | Вопрос пользователю |
| `[APPROVAL_NEEDED]` | Аппрув с inline-кнопками |
| `[STATUS]` | Статус-апдейт в свой топик |
| `[MEMORY_UPDATE]` | Сигнал что обновил context.md |
| `[FILE:/path/to/file]` | Отправить файл пользователю в TG (doc/photo) |
| `[RESTART] причина` | Перезапустить мост; после старта мост сам вернётся к агенту и резюмит сессию (в основном для Сисадмина) |

## Правила

1. Тег — команда bridge, не текст. Пиши теги в конце ответа.
2. WAITING_FOR обязателен после делегации. Без него через 60 мин compact — потеряешь контекст.
3. RESULT адресный: `[RESULT:assistant:task-42]`.
4. Тег — отдельной строкой, не в середине предложения.
5. Живой тег пиши plain text, без markdown. Inline backticks вокруг тега всё равно могут быть распарсены как команда — не используй их для примеров.
6. Примеры тегов и документацию без выполнения показывай только в fenced code block или через escape `\[DELEGATE:assistant\]`. Bridge игнорирует fenced code blocks.

## Отправка файлов пользователю

**ОБЯЗАТЕЛЬНО:** если создал файл для пользователя — отправь его тегом. Без тега файл останется на сервере, пользователь его не получит.

Используй тег `[FILE]`:

```
[FILE:/абсолютный/путь/report.pdf] Описание файла
```

- Путь — абсолютный, внутри корня установки (AIOS_ROOT) или /tmp. Файл должен существовать.
- Картинки (jpg/png/gif/webp) → отправятся как фото, остальное → как документ.
- Текст после `]` — опциональный caption.

## Пути и рабочая папка

- Твой cwd — папка твоего агента (`agents/<имя>/`). Корень системы — в переменной `$AIOS_ROOT`.
- Файлы для пользователя сохраняй в `$AIOS_ROOT/workspace/temp/<твой-агент>/` или в `/tmp/` — только из этих мест разрешена отправка через `[FILE:]`.

## Длинные результаты

Если ответ или RESULT >1000 символов — сохрани в файл (напр. `$AIOS_ROOT/workspace/temp/<agent>/<task-id>.md`), в теге верни саммари + путь.
