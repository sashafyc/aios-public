# _shared/ — общие протоколы агентов

Файлы, которые читают все агенты:

| Файл | Что |
|---|---|
| `tags.md` | Теги bridge: делегация, файлы, WAITING, аппрувы |
| `tg-format.md` | Как форматировать ответы для Telegram |
| `context-spec.md` | Как вести context.md (память агента) |
| `hierarchy.md` | Кто кому делегирует |

Каждый агент ссылается на эти файлы из своего CLAUDE.md. Меняешь протокол здесь — меняется для всех.
