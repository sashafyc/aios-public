# Приватность

aios-public — **self-hosted**: ты разворачиваешь систему на своём сервере/Mac. По
умолчанию она **ничего не отправляет наружу**. Единственный опциональный канал —
анонимные баг-репорты, и он **выключен по умолчанию**.

## Что НЕ собирается и не отправляется никогда

- Переписка с агентами, содержимое твоих файлов, тексты задач.
- API-ключи, токены, пароли (маскируются перед любой записью).
- Имя пользователя, email, имя хоста, реальные пути (`/home/<user>` → `~`).

## Баг-репорты (опционально, по умолчанию ВЫКЛ)

Чтобы помогать чинить проблемы, система может слать **анонимные технические**
баг-репорты разработчику. Управляется в `bridge/.env`:

- `AIOS_BUGREPORT=0` — выкл (по умолчанию). Баги пишутся **только локально** в `logs/bugs/`.
- `AIOS_BUGREPORT=1` + `AIOS_BUGREPORT_URL=<endpoint>` — включить отправку.

Спрашивается один раз при установке (по умолчанию «нет»). Включить/выключить позже —
скажи Сисадмину «делиться/не делиться багами» (он поменяет `.env` + рестарт).

### Что уходит в отчёте (при включённой отправке)

| Поле | Пример |
|---|---|
| `version` | `1.0.0` |
| `os` | `Linux 6.1.0` |
| `python` | `3.12.3` |
| `runner` | `claude` |
| `error_kind` | `UNKNOWN` |
| `description` | краткое тех. описание (редактированное) |
| `error` | обрезанный стектрейс/ошибка с заменой путей и маскировкой секретов |
| `install_id` | случайный UUID (анонимный, для дедупа — **не** про личность) |

Редакция перед отправкой: секреты → `***REDACTED***`, пути → `~`, длина ограничена.
**Каждый отчёт всегда дублируется локально** в `logs/bugs/bugs.jsonl` — можешь
посмотреть ровно то, что (было бы) отправлено.

### Триггеры

- Авто: только нетривиальные (неожиданные) ошибки раннера. Транзиентные
  (rate-limit, авторизация, перегрузка) **не** считаются багами и не шлются.
- Вручную: когда ты говоришь агенту «нашёл баг / не работает / почини».

### Как полностью отключить

`AIOS_BUGREPORT=0` в `bridge/.env` (или пустой `AIOS_BUGREPORT_URL`) — отправки нет.
Локальный лог можно чистить: `rm -f logs/bugs/*`.

## Для мейнтейнера: серверный endpoint (приём багов)

Клиент шлёт `POST <AIOS_BUGREPORT_URL>` с JSON-телом (поля выше), `Content-Type:
application/json`, таймаут 10с, дедуп авто-ошибок по сигнатуре на клиенте. Минимальный приёмник:

```python
# pip install fastapi uvicorn
from fastapi import FastAPI, Request
import json, time, pathlib
app = FastAPI()
DB = pathlib.Path("bugs.jsonl")

@app.post("/bugreport")
async def bugreport(req: Request):
    rep = await req.json()
    rep["received_at"] = time.strftime("%Y-%m-%dT%H:%M:%S%z")
    with DB.open("a", encoding="utf-8") as f:
        f.write(json.dumps(rep, ensure_ascii=False) + "\n")
    return {"ok": True}
# uvicorn server:app --host 0.0.0.0 --port 8088
# затем AIOS_BUGREPORT_URL=https://<твой-домен>/bugreport
```

Триаж: собираешь `bugs.jsonl`, чинишь, помечаешь в `CHANGELOG.md` «fixed in vX.Y.Z».
При обновлении у пользователя Сисадмин покажет changelog (см. `docs/RELEASING.md`).
