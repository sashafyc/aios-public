# aios-public

> Команда AI-агентов в твоём Telegram. Один бот, одна группа с топиками — каждый топик отдельный агент. Ставится одной командой.

## Что это

Готовая к установке система AI-агентов в Telegram. Из коробки три агента:

- **💬 Ассистент** — выполняет задачи: вопросы, файлы, документы (PDF/Excel/презентации).
- **⚙️ Сисадмин** — управляет системой через диалог: создаёт агентов, подключает API, переключает LLM, мониторит здоровье. Тебе не нужно лезть в конфиги.
- **🎙 Скрайбер** — транскрибация: голосовые, аудио, видео, YouTube.

Работает на любом LLM: **Claude, Codex/GPT, DeepSeek, Gemini** — выбираешь при установке, переключаешь одним параметром.

## Установка

**Не технарь? Это проще, чем кажется — три шага:**
1. Открой **Терминал** (на Mac — приложение «Терминал»; на Windows — установи [WSL2](https://learn.microsoft.com/windows/wsl/install) и открой Ubuntu; на Linux — любой терминал).
2. Вставь команду ниже и нажми Enter.
3. Дальше просто отвечай на вопросы установщика — он проведёт за руку.

```bash
curl -fsSL https://raw.githubusercontent.com/sashafyc/aios-public/main/install.sh | bash
```

Установщик за ~5 минут поможет создать группу и бота в Telegram, выбрать LLM и (по желанию) подключить голосовые. Ничего заранее знать не нужно.

**Есть Claude Code или Codex?** Дай ему ссылку на этот репозиторий и на [docs/INSTALL.md](docs/INSTALL.md) — он выступит «UI-окном»: спросит у тебя нужные значения и прогонит установщик в неинтерактивном режиме сам. Один момент: создать Telegram-бота (@BotFather) и группу с топиками может только человек, поэтому агент попросит у тебя **токен бота** и **id группы/топиков** — всё остальное (зависимости, конфиги, автозапуск) сделает за тебя.

Хочешь понимать что происходит — установщик `install.sh` читаемый и комментированный. Справка по конфигу — [docs/CONFIG.md](docs/CONFIG.md). Установка агентом и список переменных — [docs/INSTALL.md](docs/INSTALL.md).

> ⚠️ **Ставь только в приватную Telegram-группу.** Агенты работают автономно (bypass-режим) — выполняют команды и файловые операции без подтверждения на каждый шаг, чтобы реально делать работу. Это ограничено deny-list (запрет опасных команд и системных путей) и тем, что бот реагирует только в твоей группе. Любой участник группы может управлять агентами — добавляй только доверенных. Нужен жёстче контроль — задай `ALLOWED_USER_IDS` в `.env`.

## Возможности

- **Один бот — много агентов** (routing по топикам). Новый агент = новый топик.
- **Self-service через Сисадмина** — всё управление через диалог в TG.
- **Streaming** ответов в реальном времени.
- **Делегация** — агенты передают задачи друг другу, ты видишь pipeline.
- **Голосовые** → текст (AssemblyAI).
- **Auto-fallback** — упал один runner, подхватил другой.
- **Hot-reload** конфига, daily reset, keep-alive кэша, isolated cron-сессии.
