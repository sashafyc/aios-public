# Навыки (skills)

Навыки ловятся CLI нативно — пользователь пишет `/имя` или агент вызывает сам по контексту.

| Навык | Для кого | Что делает |
|---|---|---|
| `pdf` | Ассистент | Создание и чтение PDF, формы |
| `xlsx` | Ассистент | Таблицы Excel: создание, формулы, графики, чтение |
| `pptx` | Ассистент | Презентации PowerPoint |
| `create-agent` | Сисадмин | Создание нового агента (с нуля или импорт из ChatGPT/Claude) |

## Как добавить свой навык

1. Создай папку `skills/<имя>/`
2. Положи `SKILL.md` с YAML-frontmatter (`name`, `description` с триггерами)
3. Опиши что делает навык, дай примеры кода/команд
4. Готово — CLI подхватит автоматически

Подробности про формат — официальная документация по skills.
