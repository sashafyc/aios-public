# create-agent — создание нового агента

Навык Сисадмина. Два сценария: **с нуля** и **импорт из другого чата** (ChatGPT/Claude/бот).

## Шаг 0. Определи сценарий

Спроси: «Создаём агента с нуля или у тебя уже есть агент в другом чате (ChatGPT, Claude), которого хочешь перенести?»

---

## Сценарий А: с нуля

**1. Собери роль.** Спроси (по одному вопросу за раз, не вываливай всё сразу):
- Как зовут агента?
- Чем занимается? (зона ответственности)
- В каком стиле отвечает?
- Что важно знать (контекст, правила, факты о пользователе)?

**2. Выбери runner.** Спроси:
```
На каком LLM запускаем?
1) Claude — лучший tool use (файлы, bash, навыки)
2) DeepSeek — дёшево, для массовых текстовых задач
3) Codex/GPT
4) Gemini — бесплатно
```
Проверь что для выбранного runner есть авторизация/ключ (см. knowledge/system/runners.md). Если нет — сначала помоги подключить.

**3. Создай топик.** Попроси: «Создай в группе новый топик, назови его (например 🔍 Ресёрч), напиши в него любое сообщение и перешли мне — я достану topic_id». Из пересланного сообщения возьми `message_thread_id`.

**4. Создай файлы агента** (см. «Технические шаги» ниже).

---

## Сценарий Б: импорт из другого чата

**1.** Дай пользователю промпт для копирования в исходный чат:
```
Опиши себя максимально подробно для переноса в другую систему:
1. Кто ты? Роль и специализация.
2. Какие у тебя правила и принципы?
3. В каком стиле отвечаешь?
4. Какие задачи умеешь выполнять?
5. Что важно знать о пользователе?
6. Какие ограничения?
7. Базовый контекст (факты, предпочтения, история решений)?

Ответь структурированно, как инструкцию для нового ассистента,
который должен работать точно так же как ты.
```

**2.** Пользователь присылает ответ исходного агента. Разбери его, покажи краткую выжимку (роль, что знает, стиль) и спроси «Всё верно? Создаю?».

**3.** Выбери runner и создай топик (как в сценарии А, шаги 2-3).

**4.** Сформируй CLAUDE.md из импортированных инструкций, адаптировав под формат системы.

---

## Технические шаги (общие)

1. **Папка:** `agents/<name>/` (name — латиницей, lowercase, без пробелов: researcher, cook, marketer).

2. **CLAUDE.md** — структурированный, НЕ перегруженный. Секции:
   - `# <Имя> — <роль>` + топик
   - `## Ты — <Имя>` + описание роли
   - `## При старте читаешь` (CLAUDE.md, context.md, ../_shared/tags.md, tg-format.md)
   - `## Что умеешь` / `## Чего не делаешь`
   - `## Принципы` (файлы через [FILE:], текст последним в turn)
   - `## Теги`
   - Если импорт — добавь секцию `## Контекст` с фактами из исходного агента
   Бери за основу `agents/_template/CLAUDE.md`.

3. **context.md и journal.md** — скопируй из `agents/_template/`, подставь имя. Если импорт — заполни «📌 Постоянное» и «🧠 Выученное» фактами.

4. **Симлинки** (для Codex/Gemini):
   ```bash
   cd agents/<name>
   ln -sf CLAUDE.md AGENTS.md
   ln -sf CLAUDE.md GEMINI.md
   ```

5. **agents.toml** — добавь секцию:
   ```toml
   [agents.<name>]
   display_name = "<Имя>"
   topic_id = <из шага 3>
   bot_token_env = "BOT_TOKEN"
   workdir = "agents/<name>"
   model = "<модель под runner>"      # claude-sonnet-4-6 / deepseek-v4-pro / ...
   runner_type = "<claude|deepseek|codex|gemini>"
   role = "<краткая роль>"
   stream = true                       # true для claude/deepseek, false для codex/gemini
   ```
   Hot-reload подхватит за 60 сек — рестарт не нужен.

6. **Проверь:** `python3 bridge/doctor.py` — агент должен появиться без warning.

7. **Предложи делегацию:** «Хочешь чтобы Ассистент мог делегировать задачи этому агенту? Добавлю в can_delegate_to».

8. Подтверди пользователю: «✅ Агент <Имя> создан в топике <эмодзи>. Напиши ему — проверим».

## Модели по runner'ам
| runner_type | model | stream |
|---|---|---|
| claude | claude-sonnet-4-6 / claude-opus-4-6 | true |
| deepseek | deepseek-v4-pro / deepseek-v4-flash | false |
| codex | gpt-5.4-codex / o4-mini | false |
| gemini | (авто) | false |
